# АРКА 123

Одностраничный адаптивный сайт-презентация пространства для аренды под мастер-классы, семинары и встречи. Проект реализован на React и Vite.

## Запуск

```sh
npm install
npm run dev
```

Проверки production-сборки и стиля:

```sh
npm run build
npm run lint
```

## Что входит в концепцию

- Анимированная прорисовка контура арки и прелоадер; цифры 123 проявляются после того, как контур «открывает» арку. При наведении на логотип анимация повторяется.
- Главный экран с адресом, слоганом и предоставленной фотографией арочных окон.
- Концептуальная интерактивная схема помещения с переключением пустого зала, мастер-класса и семинара.
- Scroll-driven история бренда и фотореалистичный персонаж Анна с приветственным жестом.
- Блоки услуг, фотогалерея, тарифы, отзывы, контакты и форма-заготовка заявки.
- Адаптивная вёрстка, клавиатурный фокус и настройка уменьшения движения.

## Материалы и ограничения макета

В проект добавлены предоставленные рекламные материалы и обработанные фотографии интерьера. Видео переходов, план с замерами и фотографии пространства с реальной рассадкой не предоставлены.

Фотографии помещения, план с замерами, список оборудования, утверждённые цены и подлинные отзывы не были доступны среди локальных материалов. Поэтому схема зала обозначена как концептуальная визуализация, тарифы — как демонстрационные, а блок отзывов не содержит вымышленных цитат. Перед коммерческой публикацией следует заменить концептуальные материалы на проверенные данные.

Форма заявки демонстрирует интерфейс и валидацию браузера, но не отправляет данные. Перед запуском подключить согласованный email, CRM или серверный endpoint; не собирать реальные персональные данные через текущую демо-форму.

## Идея фирменного персонажа

Анна — собирательный образ хозяйки пространства 30–35 лет. Строгий графитово-зелёный костюм связывает её с интерьерной палитрой, а брошь с «123» делает персонажа частью айдентики. В скролл-сцене она приветствует посетителя и ведёт через три ключевые идеи: гостеприимство, вариативность зала и вид на Библиотеку.

## Перед передачей работы

Перед коммерческой публикацией необходимо заменить визуализации на согласованные фото/3D-рендеры помещения, указать реальные тарифы, оборудование, контакты и отзывы, а форму подключить к рабочему каналу заявок.

Для финальной сдачи тестового задания исполнитель должен самостоятельно дополнить этот файл фактическим временем работы и использованными AI-инструментами/подписками.
